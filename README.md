- 配合表情包使用更佳。
   Astrbot表情包插件：

   ```
   anka-afk/astrbot_plugin_meme_manager
   ```

   插件可从github仓库中导入表情包：
   大肥鱼表情包

   ```
   shirachino/astrbot-deepseek-meme-pack
   ```

   爱弥斯表情包

   ```
   shirachino/astrbot-Aemeath-meme-pack
   ```

   菲比啾比表情包
